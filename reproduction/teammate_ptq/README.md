# INT8 团队小结：FP32 / PTQ / QAP B / C

**QAP B 在三个种子上均优于 PTQ；补齐 C43/44 后，没有观察到量化预训练相对“FP32 预训练＋量化微调”的一致收益。** 模型与 QAP 方法来自 [berumottovv00/BioFoundation](https://github.com/berumottovv00/BioFoundation)，保留原 ARES 结构、`dt_rank=96`，使用 Brevitas 伪量化。

**数据范围：只有一个 TUAR 数据集，按录音划分，未按受试者划分。** train/val/test 为 55,524 / 6,426 / 7,211 个窗口。下表为 seeds 42/43/44 的均值 ± 样本标准差；BAcc 单位为 %。

| 方法 | AUROC | AP | 默认 BAcc | 验证阈值 BAcc |
| --- | ---: | ---: | ---: | ---: |
| FP32 | 0.9045 ± 0.0095 | 0.9233 ± 0.0061 | 83.08 ± 0.19 | 82.76 ± 0.60 |
| PTQ INT8 | 0.8707 ± 0.0082 | 0.8871 ± 0.0068 | 62.74 ± 11.07 | 77.06 ± 1.68 |
| QAP B：量化预训练＋量化微调 | 0.9021 ± 0.0055 | 0.9194 ± 0.0041 | 81.83 ± 0.70 | 82.12 ± 0.72 |
| C：FP32 预训练＋量化微调 | 0.8940 ± 0.0168 | 0.9147 ± 0.0152 | 81.77 ± 1.67 | 81.80 ± 1.68 |

1. **训练中适应量化优于本次 PTQ。** QAP B−PTQ 的 AUROC 为 +0.0314 ± 0.0041，三个种子方向一致；QAP B−FP32 均值为 −0.0024。
2. **现有结果不足以把收益归因于量化预训练。** C43/44 AUROC 为 0.900574 / 0.906471。QAP B−C 全三种子为 +0.008096 ± 0.016411；严格同初始化的 43/44 为 −0.001265 ± 0.003583，两个种子一负一正。此前仅凭 C42 得出的预训练结论应更新。
3. **PTQ 需要同时检查排序与分类阈值。** seed43 默认把 99.94% 测试窗口判为伪迹，BAcc 为 49.98%；用验证集锁定阈值后为 75.80%。阈值调整不改变 AUROC/AP。

**来源与口径：** QAP42 是队友检查点的完整 WSL 复测，严格同初始化配对只有 43/44。C 各自复用同 seed 的 FP32 预训练父模型，仅量化微调 5 轮、8,675 步；所有训练按原生 `val_loss` 选检查点。AUROC/AP 统一使用 `float64(z1)-float64(z0)`；PTQ 档位与 BAcc 阈值只在验证集选择，再锁定后评估完整测试集。
