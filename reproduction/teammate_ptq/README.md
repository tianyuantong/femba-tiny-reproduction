# TUAR INT8 试点（按录音划分）与共用训练驱动

> **正式线按受试者划分的三任务结果与运行手册见 [reproduction/formal_line/](../formal_line/README.md)。** 本目录存放正式线共用的训练、PTQ 校准、评估脚本与三个源码补丁，同时归档早期在单个 TUAR 数据集（按录音划分，55,524 / 6,426 / 7,211 个片段）上的 INT8 试点结果。

**结论：量化训练（C 与 QAP）在三个种子上都高于 PTQ，但量化预训练（QAP）相对“FP32 预训练 + 量化微调”（C）没有带来稳定提升。** 模型与 QAP 实现基于 [berumottovv00/BioFoundation](https://github.com/berumottovv00/BioFoundation)（`a2a4d44`，`dt_rank=96`，Brevitas 伪量化）。下表为种子 42 / 43 / 44 的均值 ± 样本标准差（BAcc 单位为 %）：

| 方法 | AUROC | AP | 默认阈值 BAcc | 验证集阈值 BAcc |
| --- | ---: | ---: | ---: | ---: |
| FP32 基线 | 0.9045 ± 0.0095 | 0.9233 ± 0.0061 | 83.08 ± 0.19 | 82.76 ± 0.60 |
| PTQ INT8（训练后量化） | 0.8707 ± 0.0082 | 0.8871 ± 0.0068 | 62.74 ± 11.07 | 77.06 ± 1.68 |
| C：FP32 预训练 + 量化微调 | 0.8940 ± 0.0168 | 0.9147 ± 0.0152 | 81.77 ± 1.67 | 81.80 ± 1.68 |
| QAP：量化预训练 + 量化微调 | 0.9021 ± 0.0055 | 0.9194 ± 0.0041 | 81.83 ± 0.70 | 82.12 ± 0.72 |

1. **在微调中适应量化优于 PTQ**：QAP 减 PTQ 的 AUROC 为 `+0.0314 ± 0.0041`（三个种子同向为正）；QAP 减 FP32 平均仅 `−0.0024`。
2. **收益来自量化微调，而非量化预训练**：补齐种子 43、44 的 C 组后（AUROC 分别为 `0.9006`、`0.9065`），QAP 减 C 的三种子均值为 `+0.0081 ± 0.0164`；在初始权重完全相同的种子 43、44 上为 `−0.0013 ± 0.0036`（一正一负）。
3. **PTQ 后必须在验证集上重选分类阈值**：种子 43 的 PTQ 在默认阈值 0 下把 99.94% 的测试片段判为伪迹（BAcc 跌至 `49.98%`），换成验证集选出的阈值后恢复到 `75.80%`。

**实验设置**：种子 42 的 QAP 使用队友提供的检查点在本机 WSL 复测，种子 43、44 在本机从头训练（FP32 与 QAP 共用同一初始化和 9:1 划分）。C 组直接加载同种子的 FP32 预训练模型，只做 5 轮（8,675 步）量化微调。所有训练按最低验证损失选检查点；AUROC 与 AP 统一对正负类 logit 差值 `float64(z1) - float64(z0)` 计算；PTQ 百分位档位与 BAcc 阈值只在验证集上选定。
