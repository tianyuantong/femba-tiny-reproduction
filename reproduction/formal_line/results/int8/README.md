# 正式线：FP32 与 INT8：三个随机种子的实验结果

受试者划分，种子 42 / 43 / 44。INT8 指 W8A8：权重和激活都量化到 8 位（Brevitas 伪量化，uniform）。下表是测试集 AUROC（ROC 曲线下面积）的三个随机种子下的均值 ± 样本标准差；TUSL 是事件级三分类的宏平均 AUROC，每个随机种子先取四个测试组结果的平均值。

| 任务 | FP32 | PTQ | C | QAP |
| --- | ---: | ---: | ---: | ---: |
| TUAR | 0.8663 ± 0.0064 | 0.8552 ± 0.0177 | 0.8642 ± 0.0051 | 0.8608 ± 0.0133 |
| TUAB | 0.8391 ± 0.0083 | 0.7560 ± 0.0473 | 0.8392 ± 0.0126 | 0.8510 ± 0.0069 |
| TUSL v2 | 0.8339 ± 0.0292 | 0.8194 ± 0.0228 | 0.8263 ± 0.0324 | 0.8609 ± 0.0280 |

PTQ：在 FP32 微调检查点上做训练后量化。C：FP32 预训练 + 量化微调。QAP：量化预训练 + 量化微调。

## 结论

1. **PTQ 掉得最多，C 和 QAP 与 FP32 的均值差都在 0.03 以内。** PTQ 在三个任务上均值都最低；TUAB 上三个种子都比 FP32 低 0.059–0.129。
2. **QAP 对 PTQ 的优势取决于任务。** TUAB、TUSL v2 三个种子都领先，平均 +0.095、+0.041，TUSL v2 不计任何一个测试组时，三个种子仍然都领先；TUAR 平均只有 +0.006，种子 43 落后 0.026。
3. **没有任务稳定支持量化预训练的额外收益（QAP 对 C）。** TUAR 平均 −0.003；TUAB +0.012，但种子 44 为负；TUSL v2 平均 +0.035，但全部来自一名受试者占多数的第 0 组（fold0），不计这一组后为 0.000（见 [TUSL 的稳健性](#tusl-的稳健性)）。
4. **PTQ 后要在验证集上重选阈值。** PTQ 后分数整体偏移：种子 42 的 TUAR 在默认阈值 0 下全部判为阳性，BAcc（平衡准确率，各类召回率的平均）为 0.500；换成验证集选出的阈值 1.79 后为 0.732。TUSL 按最大概率决策，PTQ 的 BAcc 只有 0.507（FP32 0.676），种子 42 的第 1 组和种子 44 的第 3 组只预测出一个类别。
5. **TUAB 微调很早就到最低验证损失**：9 个 TUAB 微调里 7 个在第 1 轮最低，之后上升（见[学习曲线](learning-curves.png)）。

## 测试数据规模与受试者分布

这里的“片段”指一段 5 秒的脑电信号；TUSL 按带有人工标注的事件统计。第 0–3 组分别对应数据目录中的 `fold0`–`fold3`。

| 任务 | 测试数据 | 受试者人数 | 数据最多的受试者所占比例 |
| --- | --- | ---: | ---: |
| TUAB | 74,010 个片段 | 253 | 1.4% |
| TUAR | 7,709 个片段 | 21 | 13.7% |
| TUSL v2 | 四个测试组共 153 个事件 | 24 | 总体为 30%，在第 0 组中为 84% |

TUAB 覆盖的受试者最多，结果受单个人数据的影响较小。TUSL 的受试者较少，结果作为补充，并分别检查四个测试组是否依赖少数受试者的数据。

## TUSL：v2 为主，v1 对照

v2 的验证集按受试者从训练组里抽（[resplit_validation.py](../../../tusl_events/resplit_validation.py)），**是看过 v1 测试结果后的探索性修订**，测试组不变。同为种子 42、20 轮，两个协议的宏平均 AUROC：

| 协议 | FP32 | PTQ | C | QAP |
| --- | ---: | ---: | ---: | ---: |
| v1 | 0.7753 | 0.7532 | 0.7392 | 0.7998 |
| v2 | 0.8003 | 0.8030 | 0.7890 | 0.8390 |

v1 只跑了种子 42。v2 的三个随机种子下的均值单独汇总，不拿它减 v1 单种子的结果当作协议收益。

## TUSL 的稳健性

第 0 组的 55 个测试事件里，46 个来自同一名受试者（29 个背景、16 个慢波、1 个发作），另外两人只有 9 个发作事件。四种方法在这个测试组的宏平均 AUROC 只有 0.44–0.85，TUSL 在不同随机种子下的结果差异主要来自这个测试组。

不计其中一个测试组，只对其余三组求平均，再计算三个随机种子的平均差值：

| 比较 | 四组全部计入 | 不计第 0 组 | 不计第 1 组 | 不计第 2 组 | 不计第 3 组 |
| --- | ---: | ---: | ---: | ---: | ---: |
| QAP − C | +0.035 | 0.000 | +0.047 | +0.047 | +0.044 |
| QAP − PTQ | +0.041 | +0.016 | +0.045 | +0.056 | +0.049 |
| C − PTQ | +0.007 | +0.016 | −0.003 | +0.009 | +0.005 |
| QAP − FP32 | +0.027 | −0.003 | +0.041 | +0.034 | +0.036 |

无论不计哪一个测试组，QAP − PTQ 在三个随机种子下都为正。QAP − C 和 QAP − FP32 的领先全部来自第 0 组：三个随机种子在这个测试组的 QAP − C 分别为 +0.169、+0.138、+0.109，其余三个测试组基本持平。

按受试者重复抽样：保持模型不变，在每个测试组内随机抽取受试者，同一个人可以被重复抽到；每次都带上这个人的全部事件。四种方法、三个随机种子使用相同的抽样结果，重复 2,000 次。

| 比较 | 观测差 | 95% 范围 | 重抽样中为正的比例 |
| --- | ---: | --- | ---: |
| QAP − C | +0.035 | −0.001 ~ +0.055 | 97% |
| QAP − PTQ | +0.041 | +0.001 ~ +0.058 | 98% |
| C − PTQ | +0.007 | −0.016 ~ +0.022 | 73% |
| QAP − FP32 | +0.027 | −0.008 ~ +0.044 | 92% |
| PTQ − FP32 | −0.014 | −0.027 ~ +0.006 | 7% |

如果某个测试组抽样后缺少一个类别，就无法计算宏平均 AUROC，需要重新抽样（占 41%）。因此，保留下来的抽样结果中，第 0 组总是包含那名数据最多的受试者，得到的范围偏乐观。以事件为单位重复抽样时 QAP − C 的范围是 +0.014 ~ +0.056；同一受试者的事件彼此相关，这种算法会高估确定性。

结论：TUSL 上 QAP 优于 PTQ 可以作为补充证据；QAP 优于 C、优于 FP32 不成立。

## 与上游协议的差异

- **划分**：上游 [FEMBA（EMBC 2025）](https://arxiv.org/abs/2502.06438v2)和 [FEMBA on the Edge（2026）](https://arxiv.org/abs/2603.26716v1)在 TUAR、TUSL 上随机 80/10/10 划分，后者写明按样本划分，同一受试者可能同时出现在训练和测试中。本页三个任务都按受试者划分，数字不能和论文直接比。TUAB 两边都用官方划分，训练与测试的受试者不重叠。
- **量化**：上游的量化实验只做了 TUAB，W8A8 PTQ 的 AUROC 从 0.89 降到 0.77，QAT 回到 0.88。本页方向一致：TUAB 上 PTQ 比 FP32 低 0.083，C 与 FP32 持平，QAP 高 0.012。
- **PTQ 做法**：本页权重逐张量量化，激活按百分位校准，从七个候选百分位中按验证集表现选择一个；上游用逐通道权重、2 的幂次激活尺度和偏置校正。早期复现按最大值校准激活时，W8A8 全部判为阳性（AUROC 0.5），原因是少数极大的激活把其余值压成 0。
- **与论文对照的 FP32**：早期复现按录音划分，TUAR 的 FP32 AUROC 为 0.924，论文为 0.937。早期复现的结果都在[历史实验结果](../../../RESULTS.md)。

## 数据和训练

- **TUAB**：预训练语料是官方训练集里的受试者，剔除 TUAR、TUSL 的测试受试者，训练集包含 586,058 个片段，验证集包含 150,967 个片段。微调取其中五分之一的受试者（训练集 / 验证集为 123,016 / 25,385 个片段）；测试使用完整的官方 eval，共 74,010 个片段，其中 34,134 个标为异常。
- **TUAR**：训练集 / 验证集 / 测试集分别包含 54,563 / 6,889 / 7,709 个片段，其中测试集有 3,928 个标为伪迹。本页与早期按录音划分的 [TUAR 试点](../../../teammate_ptq/README.md)是两套协议，数字不可比。
- **TUSL**：从每个标注事件的起点开始，连续截取两段各 5 秒的脑电信号，去掉标签冲突的事件后 296 个，三分类，未标注区间不算第四类。14 名也在预训练语料里的受试者固定在训练集，其余 24 人分成四组，轮流作为测试集，合计 153 个测试事件。同一事件的两个片段分别预测，再取预测概率的平均值来计算指标。v2 四次评估使用的验证集分别包含 88 / 78 / 68 / 94 个片段。
- **预处理**：0.1–75 Hz 带通、60 Hz 陷波，256 Hz，22 通道 TCP 双极导联，每 5 秒截取一个片段，每个片段包含 22 个通道、每通道 1280 个采样点。
- **训练、PTQ 和评估**：按[正式线协议](../../README.md#协议)。量化覆盖 35 个激活量化器和 18 个权重量化器，全部 8 位；4 个 depthwise 卷积权重保持 FP32。
- **运行环境**：一张 RTX 5060 Ti 16 GB（WSL2，驱动 591.86），torch 2.7.1+cu128、Brevitas 0.12.1、PyTorch Lightning 2.6.5。源码是上游 BioFoundation `a2a4d44` 加本仓库的三个补丁；每个阶段用的源码、运行脚本、数据和检查点哈希见 [provenance.json](provenance.json)。种子 42 的 FP32 预训练早于三值补丁，三值补丁不改 FP32 和 uniform 量化的路径。

使用原始实验输出文件复核（只用 CPU，需要 NumPy 和 scikit-learn）：

```bash
RESULTS=reproduction/formal_line/results/int8
for seed in 42 43 44; do
  python "$RESULTS/verify_binary.py" "$ART" "$RESULTS" "$seed" w8a8 tuar tuab
  python "$RESULTS/verify_tusl.py" "$ART" "$RESULTS" "$TUSL_DATA" "$seed"
done
python "$RESULTS/bootstrap_tusl.py" "$ART" "$RESULTS/summary.json" tusl-bootstrap.json
```

`ART` 是正式实验输出文件的根目录，同级要有 `subject-data-20261025`；`TUSL_DATA` 是含 `fold0`–`fold3` 的 v2 数据目录。原始预测、权重和数据不在仓库里。
