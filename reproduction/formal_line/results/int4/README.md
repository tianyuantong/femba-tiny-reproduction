# 正式线：INT4 三种子结果

受试者划分，种子 42 / 43 / 44。INT4 指 W4A8：权重 4 位、激活 8 位（Brevitas 伪量化，uniform）。下表是测试集 AUROC 在三个种子上的均值 ± 样本标准差；TUSL 为事件级三分类的宏平均 AUROC，每个种子先对四个测试组求平均。FP32 和 [INT8 结果](../int8/README.md)是同一批模型。

| 任务 | FP32 | PTQ | C | QAP |
| --- | ---: | ---: | ---: | ---: |
| TUAR | 0.8663 ± 0.0064 | 0.8429 ± 0.0372 | 0.8689 ± 0.0065 | 0.8541 ± 0.0042 |
| TUAB | 0.8391 ± 0.0083 | 0.7472 ± 0.0485 | 0.8427 ± 0.0112 | 0.8503 ± 0.0053 |
| TUSL v2 | 0.8339 ± 0.0292 | 0.8105 ± 0.0201 | 0.8134 ± 0.0314 | 0.8428 ± 0.0244 |

PTQ：在 FP32 微调检查点上做训练后量化。C：FP32 预训练 + 量化微调。QAP：量化预训练 + 量化微调。

## 结论

1. **权重降到 4 位，量化微调没有掉点。** C、QAP 和 FP32 的均值差都在 0.03 以内，和 INT8 相同。比起 INT8，存储从 9.10 MB 降到 4.85 MB，合计 BOPs 从 86.4 G 降到 64.7 G。
2. **PTQ 掉得最多。** TUAB 上三个种子比 FP32 低 0.067–0.139。TUAR 默认阈值下 BAcc 只有 0.569，种子 42 全部判为阳性，换成验证集选的阈值后恢复到 0.743。TUSL 的 BAcc 是 0.489，种子 42 的第 2 组和种子 44 的第 3 组只预测出一个类别。
3. **QAP 对 PTQ 的优势和 INT8 相近。** TUAB 三个种子都领先，平均 +0.103（INT8 +0.095）；TUSL v2 平均 +0.032，不计任何一个测试组时，三个种子仍然都领先；TUAR 平均 +0.011，种子 43、44 落后。
4. **QAP 没有比 C 带来稳定收益。** TUAR 三个种子都更低，平均 −0.015；TUAB 平均 +0.008，种子 44 为负；TUSL v2 平均 +0.029，几乎全部来自种子 43 的第 0 组（+0.313），不计这一组后是 +0.003，种子 44 为负。

## TUSL 的稳健性

第 0 组有 55 个测试事件，46 个来自同一名受试者。种子 43 的 C 在这一组只有 0.458，QAP 是 0.771，QAP − C 的均值主要来自这一个差。

不计其中一个测试组，三个种子的平均差值：

| 比较 | 四组全部计入 | 不计第 0 组 | 不计第 1 组 | 不计第 2 组 | 不计第 3 组 |

| QAP − C | +0.029 | +0.003 | +0.045 | +0.036 | +0.034 |

## 运行环境

模型源码、软件版本和 FP32 母模型都和 INT8 相同。

- **RTX 5060 Ti**：TUAB 的 PTQ、C，QAP 种子 42 的预训练和 TUAB 微调。
- **RTX PRO 6000 Blackwell**：QAP 种子 43、44 的预训练和 TUAB 微调，TUAR、TUSL 的 PTQ、C、QAP。

把 5060 Ti 上产出的四个 TUAB 检查点放到另一张卡上重放验证集，AUROC 最多差 0.00002。每个阶段用的卡记在 [provenance.json](provenance.json)。

## 文件

| 文件 | 内容 |
| --- | --- |
| [summary.json](summary.json) | 各种子、各测试组的 AUROC、AP、BAcc |
| [provenance.json](provenance.json) | 每个训练阶段和 PTQ 校准的检查点、母模型哈希、选中的轮次或百分位、GPU |
| [tusl-bootstrap.json](tusl-bootstrap.json) | TUSL 各测试组的差值、不计某个测试组后的结果和重复抽样检查 |

使用原始实验输出文件复核（只用 CPU，需要 NumPy 和 scikit-learn）：

```bash
RESULTS=reproduction/formal_line/results
for seed in 42 43 44; do
  python "$RESULTS/int8/verify_binary.py" "$ART" "$RESULTS/int4" "$seed" w4a8 tuar tuab
  python "$RESULTS/int8/verify_tusl.py" "$ART" "$RESULTS/int4" "$TUSL_DATA" "$seed" w4a8
done
python "$RESULTS/int8/bootstrap_tusl.py" "$ART" "$RESULTS/int4/summary.json" tusl-bootstrap.json w4a8
```

`ART`、`TUSL_DATA` 的含义和 [INT8 页](../int8/README.md#文件)相同。
